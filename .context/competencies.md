# Competencies

### Unity - Audio Effects
**Description**: Set up audio effects for the game.

#### Difficulty Levels
- **Easy** (2 Story Points): Adding ambient background sounds or straightforward sound effects for actions like jumping or picking up items.
- **Medium** (8 Story Points): Implementing spatial audio for immersive experiences and adaptive soundtracks that react to gameplay.
- **Hard** (16 Story Points): Designing complex audio systems, such as realistic echo/reverb based on environment or detailed audio mixing.

---

### Shared - Reverse Engineering
**Description**: Analyze an existing code base to derive its functionality.

#### Difficulty Levels
- **Easy** (4 Story Points): Analyze a small, well-documented code base to understand its basic functionality.
- **Medium** (8 Story Points): Examine a moderately complex code base, identifying key functions and components.
- **Hard** (16 Story Points): Thoroughly analyze a large, poorly documented code base to derive its complete functionality and dependencies.

---

### Shared - End-to-End Tests
**Description**: Write automated tests that cover the entire user flow.

#### Difficulty Levels
- **Easy** (6 Story Points): Automated testing of critical user flows through the UI, such as signing up or logging in, with a predefined and predictable outcome.
- **Medium** (12 Story Points): Automated testing of more complex user flows that may involve conditional logic, multiple user roles, or dynamic content.
- **Hard** (24 Story Points): Comprehensive automated testing of several related complex user flows.

### Backend - Setting up Data Lake
**Description**: Set up and/or manage a data lake in a cloud.

#### Difficulty Levels
- **Easy** (8 Story Points): Simple Data Lake Setup/Configuration. Set up a basic data lake on a cloud platform with simple storage and retrieval capabilities. This includes defining a basic folder structure, ingesting static files (e.g., CSV, JSON) using manual or basic batch ingestion methods, and setting up basic access controls.
- **Medium** (16 Story Points): Data Lake with Automated Ingestion and Data Cataloging. Set up a data lake with automated data ingestion pipelines and implement a data catalog for metadata management. This includes setting up basic ETL processes for data transformation, optimizing storage formats (e.g., Parquet or ORC), and enabling basic query capabilities.
- **Hard** (32 Story Points): Data Lake with Real-Time Streaming and/or Data Governance. Create a comprehensive data lake architecture that supports both batch and real-time data ingestion.
